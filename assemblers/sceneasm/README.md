# SceneASM adapter

Status: PLANNED / M2.0

Repository: Ploos-AS/SceneASM

The first adapter will define:

- SceneASM executable discovery;
- command-line contract;
- PRG output;
- symbol/debug metadata output;
- version capture;
- differential comparison against the 64tass reference build.

SceneASM is not yet required to build C64Scene.
