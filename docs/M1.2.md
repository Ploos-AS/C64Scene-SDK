# M1.2 — Double-IRQ raster stabilization

M1.2 introduces a real scene technique rather than a framework API.

The reference implementation separates:

1. IRQ1 — catches the requested raster line and schedules IRQ2.
2. IRQ2 — enters on the following line, corrects residual entry timing and reaches `stable_start`.
3. effect window — production-owned cycle-sensitive code.
4. restore — rearms IRQ1 for the next frame.

## Qualification contract

A routine is not called qualified merely because it assembles. Qualification must record at least:

- VIC-II model / PAL or NTSC family;
- target raster line;
- whether either phase intersects a badline;
- observed cycle position at `stable_start`;
- observed jitter;
- assembler/tool version;
- VICE version/configuration.

Later M1.x work can add alternate stabilization routines. They should be named by technique/constraints rather than hidden behind a generic high-level API.
