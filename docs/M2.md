# M2 — SceneASM integration

Goal: make SceneASM a first-class C64Scene assembler while retaining 64tass as an independent reference/oracle during qualification.

M2 must not compromise C64 authenticity to achieve cross-target uniformity.

## M2.0 acceptance criteria

- assembler selection is explicit;
- current 64tass path remains unchanged;
- SceneASM path can be added without target-side runtime overhead;
- build outputs live in assembler-specific directories;
- qualification records identify the assembler and version;
- no SceneASM-only syntax is required by core C64Scene runtime includes until the compatibility policy explicitly permits it.

## Long-term target

Static SceneASM knowledge and dynamic C64Scene measurements should meet at the same marker:

    SceneASM predicted -> stable_start -> VICE measured

A timing claim becomes especially valuable when the assembler's predicted raster/cycle position agrees with independently measured emulator evidence.
