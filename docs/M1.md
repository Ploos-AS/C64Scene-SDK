# M1 — Core ASM Foundation

M1 establishes small, directly usable assembly building blocks without creating a mandatory runtime.

## Contract

- Register definitions are plain symbols.
- Timing constants remain visible to production code.
- IRQ helpers are macros/routines only where they save repetition without hiding timing.
- No allocator, scheduler, object model, implicit state, or mandatory initialization layer.
- Zero-page ownership is decided by the production; the SDK does not silently reserve ZP addresses.
- PAL is the qualification baseline. NTSC timing is explicit and will receive dedicated examples/tests.

## Modules

- `vic/vic.inc` — VIC-II register map.
- `cia/cia.inc` — CIA1/CIA2 register map.
- `sid/sid.inc` — SID register map.
- `memory/memory.inc` — CPU port and common memory symbols.
- `irq/raster.inc` — minimal raster IRQ helpers.
- `timing/timing.inc` — PAL/NTSC timing constants.

## Next qualification work

M1.x should add a stable raster IRQ reference, cycle/badline test cases, emulator-visible labels, and automated VICE qualification. The reference code should demonstrate techniques rather than turn them into opaque APIs.
