# M1.7 — Real-emulator probe boundary

M1.7 closes the architectural gap between a real VICE executable and the M1.6 evidence adapter without inventing emulator capabilities.

`probe_double_irq.py` records the installed VICE version and delegates timing observation to a version-aware backend.

If no verified backend exists, the correct result is:

    status=UNQUALIFIED
    reason=NO_VERIFIED_TIMING_BACKEND

This is intentional. C64Scene values reproducible evidence over a green badge.

## End-to-end target

The completed path is:

    VICE -> verified backend -> raw log
         -> extract_samples.py -> CSV
         -> analyze_timing.py -> qualification result

M1.8 should qualify a concrete VICE release/interface, implement its backend, and preserve a real raw evidence sample before enabling timing qualification in CI.
