# M1.9 — 120-frame checkpoint qualification

M1.9 completes the deterministic analysis side of the VICE 3.9 textual-monitor path.

A real qualification requires at least 120 checkpoint-hit records at `stable_start`. VICE documents that a breakpoint hit includes the current raster line and cycle; C64Scene converts those records to canonical markers and then runs the M1.6/M1.5 extractor/analyzer chain.

## Pipeline

    raw VICE checkpoint log
      -> collect_checkpoint_hits.py (120 hits)
      -> canonical C64SCENE_TIMING log
      -> extract_samples.py
      -> frame,line,cycle CSV
      -> analyze_timing.py
      -> QUALIFIED_PASS / QUALIFIED_FAIL / UNQUALIFIED

## Important limitation

The VICE text monitor's checkpoint command hook cannot use `x` as an attached command. Therefore C64Scene does not claim that a simple command-hook script can automatically resume 120 stopped breakpoints. Process-control/monitor-driving is a separate concern.

M1.9 makes analysis of a genuine 120-hit raw log deterministic. A committed PASS still requires that genuine emulator evidence.
