# M1.10 — VICE binary-monitor protocol core

M1.10 starts the machine-readable VICE integration.

The VICE manual defines binary-monitor requests with a fixed header and documents checkpoint set/delete/list commands. C64Scene implements these packet encoders separately from socket and emulator lifecycle code so protocol bytes can be tested deterministically.

## Implemented

- binary request framing;
- checkpoint set (0x12);
- checkpoint delete (0x13);
- checkpoint list (0x14);
- explicit exec checkpoint operation;
- byte-level self-tests.

## Why this layer exists

The binary monitor is preferable for automated qualification because C64Scene should not depend on human-oriented monitor formatting when a structured protocol exists.

## Not yet claimed

M1.10 does not yet claim an emulator connection or timing PASS. The next layer must launch/connect to VICE, negotiate responses/events, set a checkpoint at `stable_start`, and obtain the machine state needed for raster/cycle qualification.
