# M1.8 — VICE 3.9 timing backend

The first concrete timing backend targets the VICE 3.9 textual monitor.

VICE documents that a breakpoint hit includes current raster line and cycle. C64Scene parses only that documented checkpoint-hit shape and emits canonical timing markers.

This moves the chain from an abstract adapter contract to a concrete emulator interface, while retaining a strict rule: no real sample means no qualification PASS.

## Target

- emulator: x64sc / VICE 3.9
- video standard: PAL
- marker: `stable_start`
- source: textual monitor checkpoint-hit raster line/cycle
- required qualification sample: >= 120 frames

## Current state

Backend: implemented.

120-frame run: not yet recorded in repository.

Timing qualification: UNQUALIFIED until the real run is captured and analyzed.
