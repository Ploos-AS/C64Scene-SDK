# M1.5 — Raster/cycle measurement

M1.5 defines the evidence format and qualification calculation independently of any particular VICE monitor text format.

## Sample contract

The analyzer consumes CSV:

    frame,line,cycle

Each row represents one observed arrival at the routine's documented stable marker. The adapter that extracts these observations from VICE must preserve raw emulator evidence alongside the CSV.

## Default criterion

The initial strict criterion is:

- at least 120 frames;
- one and only one observed `(raster line, cycle)` position across the sample.

This intentionally measures stability, not whether the chosen cycle is optimal.

The analyzer returns:

- `QUALIFIED_PASS` when every measured frame has the same line/cycle;
- `QUALIFIED_FAIL` when sufficient samples exist but positions differ;
- `UNQUALIFIED` when there is insufficient evidence.

## Evidence integrity

Synthetic/example samples may test the analyzer but may never be used as qualification evidence. A PASS committed under `qualification/results/` must identify and retain the emulator/raw-data provenance.
