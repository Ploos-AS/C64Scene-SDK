# M2.3 — stable-raster differential assembler qualification

M2.3 extends the SceneASM differential gate from the minimal hello-raster
artifact to the stable raster IRQ baseline.

Qualification target:

    examples/stable-raster/main.asm

Run:

    make differential-stable

Artifacts are preserved per qualification case:

    build/differential/stable-raster/64tass/main.prg
    build/differential/stable-raster/64tass/main.labels
    build/differential/stable-raster/sceneasm/main.prg
    build/differential/stable-raster/sceneasm/main.labels

Results use the same classification as M2.2:

- `MATCH` — PRG files are byte-for-byte identical.
- `MISMATCH` — both assembled successfully, but bytes differ.
- `UNQUALIFIED` — one or both assemblers could not build the source.

## Current status

Status: **PENDING**

SceneASM support needed by this source has been implemented, including `.text`,
forward origin handling, and the CLI/PHA/PLA opcodes. However, no M2.3 PASS is
recorded until a pinned SceneASM revision passes its own CI and the C64Scene
differential job reports `status=MATCH`.

The previous C64Scene attempt was blocked while building SceneASM and therefore
is not evidence of an assembler mismatch.

## PASS criteria

A PASS record must include:

- exact C64Scene commit;
- exact pinned SceneASM commit;
- successful SceneASM CI for that revision;
- C64Scene GitHub Actions run and differential job;
- SceneASM version;
- exact `status=MATCH bytes=N` result.

Scope: even a successful M2.3 differential result proves assembler
byte-equivalence for `examples/stable-raster/main.asm` only. It does **not**
prove raster IRQ timing stability, cycle-exact execution, or VICE runtime
qualification. Those remain separate runtime/timing gates.
